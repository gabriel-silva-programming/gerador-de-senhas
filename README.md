 🔐 Gerador de Senhas

Projeto desenvolvido com **HTML, CSS e JavaScript** durante meus estudos de desenvolvimento web.

 💻 Sobre o projeto

O Gerador de Senhas permite criar senhas aleatórias e personalizadas de forma simples e rápida.

⚙️ Funcionalidades

- Geração de senhas aleatórias.
- Controle do tamanho da senha.
- Escolha do comprimento entre 5 e 25 caracteres.
- Interface simples e intuitiva.

 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

 📚 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar meus conhecimentos em desenvolvimento web, lógica de programação e manipulação de elementos com JavaScript.
